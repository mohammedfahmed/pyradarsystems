# Project Scope

PyRadarSystems is planned as an open, validation-first framework spanning radar waveforms, RF impairments, phased arrays, propagation, target and scene models, radar processing, detection, estimation, tracking, hardware I/O, visualization, and reproducible experiments.

Version 0.1.0 implements the first complete vertical slice: 77-GHz FMCW TDM-MIMO point-target simulation and range-Doppler-angle processing. The API will expand without making the project automotive-only or FMCW-only.
