# Project scope

PyRadarSystems is planned as an open, validation-first framework spanning radar waveforms, RF impairments, phased arrays, propagation, target and scene models, radar processing, detection, estimation, tracking, hardware I/O, visualization, and reproducible experiments.

Version 0.1 implemented the first complete vertical slice: 77-GHz FMCW TDM-MIMO point-target simulation and range-Doppler-angle processing.

Version 0.2 adds a reproducible research layer, explicit aperture-taper power policies, element patterns, pattern metrics, basic CRLB utilities, and an initial transparent distributed-clutter model. The API will continue to expand without making the project automotive-only or FMCW-only.
